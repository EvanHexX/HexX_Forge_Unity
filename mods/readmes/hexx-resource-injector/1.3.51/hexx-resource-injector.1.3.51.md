# ResourceInjector 사용 안내

`ResourceInjector`는 영웅의 특수 초상화를 WebM, PNG, AssetBundle 항목으로 교체할 수 있는 BepInEx 모드입니다.

## 설치

압축 파일 안의 `BepInEx` 폴더를 게임 설치 폴더에 그대로 덮어씌우세요.

설치 후 DLL 위치는 다음과 같아야 합니다.

```text
BepInEx/plugins/ResourceInjector/ResourceInjector.dll
```

게임을 한 번 실행하면 ResourceInjector용 폴더가 자동으로 만들어집니다.

```text
BepInEx/plugins/ResourceInjector/
  config/
  portraits/
    webm/
    png/
    bundles/
  packs/
```

## 업데이트 내용

- `beta` 표기를 제거한 정식 릴리즈입니다.
- 초상화 정보 파일의 `bonus` / `amount`가 실제 능력치에 적용됩니다.
- 능력치는 저장 파일을 직접 고치지 않고, 게임 실행 중에만 적용됩니다.
- 저장 직전에는 ResourceInjector가 넣은 능력치를 제거하고, 저장 직후 다시 적용합니다.
- 영웅 상세 화면을 열지 않아도 전투/능력치 갱신 시 적용되도록 보정했습니다.
- 특수 초상화 변경 직후 영웅 상세 화면의 능력치 숫자가 바로 갱신되도록 보정했습니다.
- 주인공 `characterId = 0`의 기존 설정이 새 게임 주인공에게 잘못 적용되지 않도록 세이브별로 분리했습니다.
- 기존 버전에서 주인공에게 적용했던 특수 초상화는 안전을 위해 자동 적용되지 않을 수 있습니다. 해당 세이브에서 한 번 다시 적용하면 이후부터 세이브별로 유지됩니다.
- NPC나 동료처럼 `characterId`가 0이 아닌 캐릭터의 기존 설정은 그대로 유지됩니다.

## 기본 사용법

1. 초상화 파일을 알맞은 폴더에 넣습니다.
    - WebM: `BepInEx/plugins/ResourceInjector/portraits/webm/`
    - PNG: `BepInEx/plugins/ResourceInjector/portraits/png/`
    - Bundle: `BepInEx/plugins/ResourceInjector/portraits/bundles/`
2. 게임에서 영웅 상세 화면을 엽니다.
3. `특수 초상화` 체크박스를 켭니다.
4. 옆의 설정 버튼을 눌러 초상화를 선택합니다.
5. `변경 확인`을 눌러 적용합니다.

체크박스를 끄면 ResourceInjector 초상화가 해제되고 원래 초상화로 돌아갑니다.

## 초상화 정보 파일

초상화 표시명, 설명, 성별 제한, 보너스 능력치는 다음 파일에서 설정합니다.

```text
BepInEx/plugins/ResourceInjector/config/portrait_file_infos.json
```

간단한 예시는 다음과 같습니다.

```json
{
  "version": 1,
  "files": {
    "portraits/png/sample.png": {
      "displayName": "샘플 초상화",
      "gender": "not_specified",
      "bonus": "근력",
      "amount": 5
    }
  }
}
```

`bonus`에는 아래 표의 텍스트를 넣고, `amount`에는 입력형식에 맞는 숫자를 넣으면 됩니다.

## amount 입력 규칙

- `1`은 능력치 `+1`처럼 정수형 수치에 사용합니다.
- `0.01`은 `1%`에 해당하는 비율형 수치에 사용합니다.
- `0.05`는 `5%`입니다.
- 비율형 수치에 `1` 또는 `1.0`을 넣으면 보통 `100%`급 수치가 되므로 주의하세요.
- `amount`는 따옴표 없이 숫자로 입력하세요.

## 보너스 입력 예시

기문을 5 올리고 싶을 때:

```json
{
  "bonus": "기문",
  "amount": 5
}
```

치명타를 1% 올리고 싶을 때:

```json
{
  "bonus": "치명타",
  "amount": 0.01
}
```

속도를 5% 올리고 싶을 때:

```json
{
  "bonus": "속도",
  "amount": 0.05
}
```

## 주의사항

- 한 초상화에는 현재 `bonus` 하나만 적용할 수 있습니다.
- `bonus` 텍스트는 위 표에 있는 이름을 사용하는 것을 권장합니다.
- `저항`은 의미가 넓으므로 가능하면 `피해저항`, `부정저항`, `부상저항`처럼 구체적인 이름을 사용하세요.
- 기존 버전의 주인공 초상화 설정은 새 게임 오염 방지를 위해 자동 적용되지 않을 수 있습니다. 해당 세이브에서 다시 적용하면 됩니다.
- ResourceInjector를 제거하면 실행 중 능력치 보너스는 더 이상 적용되지 않습니다.

## 문제 확인

적용이 안 되는 항목이 있으면 다음 정보를 함께 확인해 주세요.

- 사용한 초상화 파일 또는 bundle 항목
- 입력한 `bonus`
- 입력한 `amount`
- 기대한 능력치 변화
- 실제 능력치 변화
- `BepInEx/LogOutput.log`의 ResourceInjector 관련 로그
