# Asset Forge 사용설명서

## 개요

Asset Forge는 Unity 게임 리소스를 백업하고, 텍스처, 폰트, 어셋팩을 적용하는 화면입니다. 게임 원본 파일을 직접 다루는 기능이 포함되어 있으므로, 적용 전에 백업 상태를 먼저 확인하는 것이 중요합니다.

## 시작하기 전 준비

1. Settings에서 게임 설치 폴더를 저장합니다.
2. Asset Forge 상단 또는 Home 상태판에서 백업 상태를 확인합니다.
3. 처음 사용하는 경우 Font와 Asset 백업을 먼저 만듭니다.
4. 교체할 PNG, 폰트 파일, 어셋팩 ZIP을 준비합니다.

[스크린샷: 어떤내용의 스크린샷을 넣어주세요 - Home 상태판에서 백업 상태가 보이는 화면]

## 화면 구성

- 백업 영역: Font와 Asset 백업 상태를 확인하고 백업을 실행합니다.
- 복원하기: 마지막 백업 파일을 게임 폴더에 다시 덮어씁니다.
- 텍스처 교체 작업: 원본 target을 선택하고 PNG를 적용합니다.
- 어셋팩 작업: 여러 교체 대상을 묶은 pack을 가져오고 전체 적용합니다.
- 폰트 교체 작업: 게임 폰트를 추출, 추가, 교체, 복원합니다.
- 개발자 도구: catalog 편집과 어셋팩 배포 파일 생성을 위한 영역입니다.

[스크린샷: 어떤내용의 스크린샷을 넣어주세요 - Asset Forge의 백업 영역과 복원 버튼이 보이는 화면]

## 주요 기능 사용 방법

### 백업 만들기

1. 백업할 항목을 Font, Asset 중에서 선택합니다.
2. 백업하기 버튼을 누릅니다.
3. 확인창의 내용을 읽고 진행합니다.
4. 완료 알림이 표시되면 백업 상태를 다시 확인합니다.

같은 타입의 백업은 마지막 백업 1개만 유지됩니다. 게임이 업데이트되지 않았다면 같은 원본 기준으로 반복 백업할 필요는 없습니다.

### 백업 복원하기

1. 복원하기 버튼을 누릅니다.
2. 확인창에서 복원 대상과 덮어쓰기 안내를 확인합니다.
3. 진행하면 마지막 백업 파일이 게임 폴더에 복사됩니다.
4. 복원 후 게임을 실행해 상태를 확인합니다.

복원은 현재 게임 파일을 백업본으로 덮어쓰는 작업입니다. 필요한 경우 현재 파일을 별도로 보관한 뒤 진행하세요.

### 텍스처 직접 교체

1. 텍스처 교체 작업 탭을 엽니다.
2. 원본 대상 catalog item을 선택합니다.
3. 교체할 PNG 파일을 선택합니다.
4. 미리보기와 대상 정보를 확인합니다.
5. 적용 버튼을 누릅니다.

PNG 크기나 포맷이 대상과 맞지 않으면 적용이 실패할 수 있습니다. 실패 메시지가 나오면 파일 크기, 투명도, 대상 선택을 확인하세요.

### 어셋팩 가져오기와 전체 적용

1. 어셋팩 추가 버튼을 누릅니다.
2. 온라인 또는 로컬 탭에서 pack을 선택합니다.
3. 가져온 pack을 팩 선택 목록에서 고릅니다.
4. pack target 목록과 미리보기를 확인합니다.
5. 팩 전체 적용 버튼을 누릅니다.

팩 전체 적용은 여러 target을 한 번에 바꾸는 작업입니다. 적용 전 백업 상태를 반드시 확인하세요.

[스크린샷: 어떤내용의 스크린샷을 넣어주세요 - 어셋팩 선택 목록과 target 미리보기가 보이는 화면]

### 폰트 추출과 교체

1. 폰트 교체 작업 탭을 엽니다.
2. 폰트 추출 버튼으로 원본 폰트를 추출합니다.
3. 폰트 추가 버튼으로 `.ttf`, `.otf`, `.ttc`, `.fontdata` 파일을 등록합니다.
4. 테이블에서 교체할 path id 행의 교체폰트를 선택합니다.
5. 선택 폰트 적용 버튼을 누르고 확인창에서 진행합니다.

현재폰트와 교체폰트 미리보기를 비교하면서 선택하세요. 일부 폰트는 게임 내 표시 폭이나 줄바꿈이 달라질 수 있습니다.

### 개별 폰트 복원

1. 폰트 테이블에서 복원할 행을 우클릭합니다.
2. 복원하기 메뉴를 선택합니다.
3. 해당 path id만 원본 기준으로 복원됩니다.

## 주의사항

- 게임 실행 중에는 리소스 적용을 피하는 것을 권장합니다.
- 백업 없이 텍스처나 폰트를 적용하면 원본 복구가 어려울 수 있습니다.
- 어셋팩은 대상 게임과 버전이 맞는지 확인하세요.
- 폰트 교체 후 표시가 어색하면 즉시 복원하거나 다른 폰트를 선택하세요.
- 개발자 도구에서 catalog를 수정하면 앱에 표시되는 target 정보가 바뀝니다.

## 자주 겪는 상황

### 백업 필요 메시지가 계속 표시됩니다

Settings의 게임 설치 폴더가 올바른지 확인하세요. 폴더가 맞다면 Font와 Asset 백업을 각각 실행해야 합니다.

### 텍스처 적용이 실패합니다

PNG 크기, 선택한 target, 게임 설치 폴더, 백업 상태를 확인하세요. UI Texture 대상은 지정된 크기와 정확히 맞아야 할 수 있습니다.

### 폰트를 추가했는데 목록에 보이지 않습니다

지원 확장자인지 확인하고, 파일을 다시 추가해 보세요. 등록된 폰트는 앱의 `storage/fonts` 기준으로 표시됩니다.
