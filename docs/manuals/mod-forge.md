# Mod Forge 사용설명서

## 개요

Mod Forge는 BepInEx 기반 모드를 HexX Forge 안에서 추가, 활성화, 비활성화, 삭제할 수 있는 화면입니다. DLL 1개로 된 단일 모드와 여러 파일을 포함한 패키지형 모드를 함께 관리합니다.

이 화면은 게임 폴더 안의 `BepInEx` 구조를 기준으로 동작합니다. 모드를 적용하기 전에 Settings에서 게임 설치 폴더를 먼저 설정하세요.

## 시작하기 전 준비

1. Settings에서 지원 게임과 설치 폴더를 저장합니다.
2. 게임 폴더에 BepInEx가 설치되어 있는지 확인합니다.
3. 모드 파일이 DLL인지, 배포 ZIP인지 확인합니다.
4. 이미 게임 폴더에 수동 설치한 모드가 있다면 같은 파일을 중복 활성화하지 않도록 주의합니다.

## 화면 구성

- 상단 도구 영역: 모드 추가, 모드 패킹 같은 주요 작업을 시작합니다.
- 모드 목록: 설치된 모드 패키지와 DLL 상태를 표시합니다.
- 사용 체크박스: 모드 또는 패키지를 활성화하거나 비활성화합니다.
- 상태 표시: 활성, 비활성, 혼합 상태를 보여줍니다.
- 내보내기 버튼: 설치된 모드를 다시 배포 가능한 ZIP 파일로 저장합니다.
- 설정 버튼: 모드가 설정 UI 또는 설정 파일을 제공할 때 사용할 수 있습니다.
- 삭제 버튼: 등록된 모드와 관련 파일을 삭제합니다.

## 주요 기능 사용 방법

### 로컬 모드 추가

1. Mod Forge에서 모드 추가 버튼을 누릅니다.
2. 로컬 탭을 선택합니다.
3. DLL 또는 배포 ZIP 파일을 선택합니다.
4. 표시 이름, 제작자, 설명을 확인합니다.
5. 추가 버튼을 누르면 모드가 목록에 등록됩니다.

ZIP 모드는 `mod-info.json` 또는 `hexx-mod-info.json`이 포함된 배포 ZIP을 권장합니다. 단순 압축 파일은 내부 구조를 확인할 수 없거나 설치가 제한될 수 있습니다.

### 온라인 모드 추가

1. 모드 추가 창에서 온라인 탭을 선택합니다.
2. 목록에서 설치할 모드를 고릅니다.
3. 설치 또는 업데이트 버튼을 누릅니다.
4. 설치가 끝나면 모드 목록에서 상태를 확인합니다.

온라인 목록이 비어 있으면 네트워크 상태 또는 catalog 배포 상태를 먼저 확인하세요.

### 모드 활성화와 비활성화

1. 모드 목록에서 사용할 모드의 체크박스를 켭니다.
2. 비활성화하려면 체크박스를 끕니다.
3. 패키지형 모드는 상위 패키지를 켜면 포함된 DLL과 관련 파일이 함께 처리됩니다.

활성화 중 같은 위치에 이미 DLL이 있으면 HexX Forge는 덮어쓰지 않고 경고를 표시할 수 있습니다. 이 경우 기존 파일을 직접 확인한 뒤 다시 시도하세요.

### 모드 설정 열기

1. 설정 아이콘이 활성화된 모드를 찾습니다.
2. 설정 아이콘을 누릅니다.
3. 모드가 제공하는 CFG, 파일 관리, JSON 관리 항목을 수정합니다.
4. 적용 버튼을 눌러 저장합니다.

설정 파일이 아직 생성되지 않은 모드는 게임을 한 번 실행한 뒤 다시 열어야 할 수 있습니다.

### 모드 패킹

모드 제작자는 모드 패킹 기능으로 배포 ZIP을 만들 수 있습니다.

1. 모드 패킹 버튼을 누릅니다.
2. 패키지 이름, 제작자, 설명을 입력합니다.
3. DLL 또는 ZIP 파일을 추가합니다.
4. 필요한 경우 설정 Script를 작성합니다.
5. 저장 위치를 선택하고 패킹을 실행합니다.

패킹 결과는 로컬 모드 목록에도 비활성 상태로 등록됩니다.

### 모드 내보내기

설치된 모드를 다른 사람에게 전달하거나 다시 보관하려면 모드 목록의 내보내기 기능을 사용합니다.

1. 모드 목록에서 내보낼 모드를 찾습니다.
2. 해당 행의 내보내기 아이콘을 누르거나, 모드를 우클릭한 뒤 내보내기를 선택합니다.
3. 저장할 ZIP 파일 경로를 선택합니다.
4. 저장된 ZIP 파일은 `모드 추가 > 로컬` 탭에서 ZIP 파일로 다시 추가할 수 있습니다.

내보내기 ZIP에는 `mod-info.json`이 새로 생성되며, 모드 이름, 제작자, 설명, 버전, 종속 모드 정보, 파일 목록이 포함됩니다. 활성/비활성 상태나 온라인 catalog 추적 정보는 포함되지 않습니다.

내보내기는 HexX Forge가 관리하는 설치 원본을 기준으로 ZIP을 만듭니다. 사용자가 게임 폴더에서 직접 수정한 설정 파일 내용은 자동으로 포함되지 않을 수 있으므로, 배포용 설정 파일이 필요하면 모드 패킹 단계에서 포함하거나 패킹 원본을 먼저 갱신하세요.

## 주의사항

- 모드를 활성화하기 전 게임을 종료하는 것을 권장합니다.
- 서로 같은 DLL 경로나 설정 파일을 사용하는 모드는 충돌할 수 있습니다.
- 패키지형 모드를 삭제하면 관련 파일과 폴더도 함께 제거될 수 있습니다.
- 내보내기 ZIP은 재설치 가능한 배포용 파일이며, 현재 모드의 활성 상태를 백업하는 기능은 아닙니다.
- 종속 모드는 main mod가 설치되어 있고 활성 상태일 때만 정상 동작합니다.
- 수동으로 게임 폴더에 넣은 파일은 HexX Forge가 관리하는 파일과 상태가 다를 수 있습니다.

## 자주 겪는 상황

### 모드를 켰는데 게임에서 적용되지 않습니다

게임 설치 폴더가 올바른지, BepInEx가 설치되어 있는지, 모드가 현재 게임 버전과 호환되는지 확인하세요. 설정 파일이 필요한 모드는 게임을 한 번 실행해야 설정 파일이 생성될 수 있습니다.

### 활성화할 때 경고가 표시됩니다

대상 위치에 같은 이름의 파일이 이미 있을 가능성이 높습니다. 기존 파일을 직접 확인하고, 필요한 경우 백업한 뒤 정리하세요.

### 설정 버튼이 비활성화되어 있습니다

해당 모드가 HexX Forge용 설정 Script 또는 편집 가능한 config 파일을 제공하지 않는 상태입니다.
