# Settings 사용설명서

## 개요

Settings는 HexX Forge의 기본 환경을 설정하는 화면입니다. 지원 게임, 게임 설치 폴더, Theme, Typography, Language, 앱 업데이트 상태를 한 곳에서 관리합니다.

다른 기능이 게임 파일을 찾거나 사용자 언어를 표시하려면 Settings 값이 먼저 저장되어 있어야 합니다.

## 시작하기 전 준비

1. 설치된 게임 폴더 위치를 확인합니다.
2. 사용할 UI 언어를 정합니다.
3. 원하는 Theme와 Typography가 있으면 선택할 준비를 합니다.
4. 앱 업데이트를 확인하려면 네트워크 연결 상태를 확인합니다.

## 화면 구성

- 지원 게임: HexX Forge가 관리할 게임을 선택합니다.
- Theme: 앱 색상 테마를 선택합니다.
- Typography: 앱 글꼴 스타일을 선택합니다.
- Language: 표시 언어를 선택합니다.
- 게임 설치 폴더: 선택한 게임의 설치 폴더를 저장합니다.
- 앱 업데이트: 현재 버전, 최신 버전, 다운로드, 설치 재시작 상태를 확인합니다.
- 저장 버튼: 변경한 게임 설치 폴더를 저장합니다.

## 주요 기능 사용 방법

### 지원 게임 선택

1. 지원 게임 목록을 엽니다.
2. 관리할 게임을 선택합니다.
3. 선택한 게임에 맞는 설치 폴더 안내 문구를 확인합니다.

지원 게임을 바꾸면 해당 게임에 저장된 설치 폴더가 화면에 반영됩니다.

### 게임 설치 폴더 저장

1. 게임 설치 폴더 영역에서 선택 버튼을 누릅니다.
2. 실제 게임 실행 파일 또는 데이터 폴더가 있는 설치 폴더를 선택합니다.
3. 경로가 입력되면 저장 버튼을 누릅니다.
4. Home으로 돌아가 현재 게임과 백업 상태를 확인합니다.

경로가 비어 있으면 Home의 게임 실행과 Asset Forge 백업 상태 확인이 제한될 수 있습니다.

### Theme 변경

1. Theme 목록을 엽니다.
2. 원하는 테마를 선택합니다.
3. 앱 화면 색상이 즉시 바뀌는지 확인합니다.

테마 이름은 설정 파일에 등록된 표시 이름을 그대로 사용합니다.

### Typography 변경

1. Typography 목록을 엽니다.
2. 원하는 글꼴 스타일을 선택합니다.
3. 화면의 글자 크기와 표시 상태를 확인합니다.

글꼴에 따라 일부 텍스트 폭이 달라질 수 있습니다. 버튼이나 표의 텍스트가 잘리는 경우 다른 Typography를 선택해 확인하세요.

### Language 변경

1. Language 목록을 엽니다.
2. English, 한국어, 简体中文 중 하나를 선택합니다.
3. Settings와 Home의 주요 문구가 선택한 언어로 바뀌는지 확인합니다.

일부 개발 중인 화면은 아직 i18n migration이 끝나지 않아 모든 문구가 즉시 바뀌지 않을 수 있습니다.

### 앱 업데이트 확인

1. 업데이트 확인 버튼을 누릅니다.
2. 현재 버전과 최신 버전 정보를 확인합니다.
3. 새 버전이 있으면 다운로드 버튼을 누릅니다.
4. 다운로드가 끝나면 설치 후 재시작 버튼을 누릅니다.

업데이트 중에는 앱을 종료하지 않는 것을 권장합니다.

## 주의사항

- 게임 설치 폴더를 잘못 지정하면 모드, 어셋, 게임 실행 기능이 정상 동작하지 않습니다.
- 게임별로 설치 폴더가 따로 저장되므로 지원 게임을 바꾼 뒤 경로를 다시 확인하세요.
- 업데이트 설치 후에는 앱이 재시작될 수 있습니다.
- Theme와 Typography는 앱 표시 환경만 바꾸며 게임 파일에는 영향을 주지 않습니다.

## 자주 겪는 상황

### Home에서 게임 실행 버튼이 비활성화됩니다

Settings의 게임 설치 폴더가 비어 있거나 올바르게 저장되지 않은 상태일 수 있습니다. 경로를 다시 선택하고 저장하세요.

### 언어를 바꿨는데 일부 화면이 그대로입니다

일부 화면은 아직 다국어 전환이 완전히 적용되지 않았을 수 있습니다. Settings와 Home은 언어 변경이 바로 반영되어야 합니다.

### 업데이트 확인이 실패합니다

네트워크 연결, GitHub Releases 접근 가능 여부, 현재 앱 실행 환경을 확인하세요. 실패 메시지가 표시되면 내용을 복사해 문제 확인에 사용할 수 있습니다.
